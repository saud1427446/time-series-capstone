## Project Overview
This repository contains the final capstone project for the Time Series Forecasting AI Systems course. The goal is to take a raw time series, perform diagnostics, fit classical and ML models, and evaluate them using a walk-forward backtesting framework with probabilistic forecasting.

## Dataset Chosen
**Dataset:** `economic_indicator.csv`

**Why?** I chose this dataset because it is a short, low-frequency monthly series (108 points). This presents a unique challenge and demonstrates that classical models (like Holt-Winters) are often more appropriate and robust than complex ML models (like LightGBM) when history is highly constrained.

## How to Run
The project is completely contained in a single Colab notebook. You can open and run this notebook directly in Google Colab.
